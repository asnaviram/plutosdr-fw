# Boot Sequence Documentation

## Complete Boot Flow

```
┌────────────────────────────────────────────────────────────┐
│ Phase 1: ROM Bootloader (Xilinx FPGA ROM)                 │
├────────────────────────────────────────────────────────────┤

Power-on
    │
    ▼
┌──────────────────────────────────────┐
│ Zynq ROM Bootloader executes         │
│ • Hardcoded in Zynq silicon          │
│ • Initializes PS7 (ARM + memory)     │
│ • Loads FSBL from QSPI at 0x0       │
│ • Executes FSBL                      │
└──────────────────────────────────────┘
```

### Phase 1 Details

```
ROM Bootloader Operations:
├─ Reset handler setup
│  └─ Vector table configuration
│  └─ Exception handlers
│
├─ Memory initialization
│  └─ Temporary memory for FSBL loading
│  └─ Stack pointer setup
│
├─ QSPI Flash boot mode detection
│  └─ Check QSPI controller availability
│  └─ Read boot.bin header
│
├─ FSBL loading
│  └─ Read FSBL from QSPI offset 0x0
│  └─ Decompress (if applicable)
│  └─ Verify checksums
│
└─ FSBL execution
   └─ Jump to FSBL entry point
   └─ Transfer control to first-stage bootloader
```

## Phase 2: First-Stage Bootloader (FSBL)

```
┌────────────────────────────────────────────────────────────┐
│ Phase 2: FSBL (First-Stage Bootloader)                    │
├────────────────────────────────────────────────────────────┤

FSBL Execution (~50 KB binary)
    │
    ├─ C runtime initialization
    │  └─ Clear BSS section
    │  └─ Initialize stack
    │  └─ Call constructors (C++)
    │
    ├─ PS7 Initialization
    │  └─ Run ps7_init.tcl (Vivado-generated)
    │  ├─ Clock distribution setup
    │  ├─ DDR3 memory controller init
    │  ├─ I/O bank configuration
    │  └─ Peripheral clock gating
    │
    ├─ QSPI Flash controller setup
    │  └─ Configure for next-stage read
    │  └─ Set clock dividers
    │
    ├─ U-Boot loading
    │  └─ Read U-Boot from QSPI boot.bin
    │  └─ Decompress to DDR3
    │  └─ Verify checksums/signatures
    │
    └─ Jump to U-Boot entry point
       └─ Transfer control: PS7 → U-Boot
       └─ Preserve PS7 state
```

### FSBL Source Structure

```
FSBL code (generated by XSCT):
├─ fsbl.c (main)
│  └─ Setup, load next stage
│
├─ ps7_init.c (PS7 initialization)
│  └─ Xilinx-generated from HW design
│  └─ Exact hardware configuration
│
├─ ps7_init_gpl.c (GPL portion)
│  └─ Memory controller init
│  └─ Low-level hardware setup
│
└─ Boot utilities
   ├─ QSPI read functions
   ├─ Decompression
   └─ Checksum verification

Location after build:
build/sdk/fsbl/Release/fsbl.elf (~50 KB)
```

## Phase 3: U-Boot Bootloader

```
┌────────────────────────────────────────────────────────────┐
│ Phase 3: U-Boot (Second-Stage Bootloader)                 │
├────────────────────────────────────────────────────────────┤

U-Boot execution (~750 KB ELF)
    │
    ├─ Architecture initialization
    │  └─ board_init_f (before relocation)
    │  ├─ CPU identification
    │  ├─ Serial console setup (115200 baud)
    │  ├─ Temporary RAM setup
    │  └─ Device tree blob relocation
    │
    ├─ Memory relocation
    │  └─ Copy U-Boot to high memory
    │  └─ Reconfigure memory mapping
    │  └─ Clear old code area
    │
    ├─ board_init_r (after relocation)
    │  ├─ Permanent board setup
    │  ├─ Device tree parsing
    │  ├─ Device driver initialization
    │  │  ├─ GPIO setup
    │  │  ├─ SPI initialization
    │  │  └─ I2C setup
    │  ├─ Network interface (Ethernet)
    │  └─ DFU gadget mode (USB)
    │
    ├─ Environment loading
    │  └─ Read environment from QSPI mtd1
    │  └─ Parse environment variables
    │  └─ Apply bootcmd sequence
    │
    ├─ FIT Image loading
    │  └─ Read pluto.itb from QSPI mtd3
    │  └─ Decompress components
    │  ├─ Device tree blob selection (RevA/B/C)
    │  ├─ Linux kernel decompression
    │  ├─ FPGA bitstream extraction
    │  ├─ Rootfs extraction
    │  └─ Verify checksums (MD5/SHA256)
    │
    ├─ FPGA Configuration
    │  └─ Program FPGA with bitstream
    │  └─ Initialize FPGA fabric
    │  └─ Wait for FPGA ready signal
    │
    └─ Kernel boot
       └─ Set kernel command-line arguments
       └─ Set device tree pointer (r2)
       └─ Jump to kernel entry point (0x8000)
       └─ Transfer control: U-Boot → Linux kernel
```

### U-Boot Commands

The U-Boot interactive command line (if bootcmd fails):

```
=> printenv
# Show environment variables

=> setenv bootcmd 'bootm 0x3000000'
# Change boot command

=> saveenv
# Save environment to QSPI

=> dfu 0 mmc 0
# Enter DFU mode (USB firmware update)

=> sf probe
# Probe SPI flash

=> sf read 0x2000000 0x200000 0x1000000
# Read from QSPI to RAM

=> bootm 0x3000000
# Boot from address (manual boot)

=> help
# Show available commands
```

## Phase 4: Linux Kernel Boot

```
┌────────────────────────────────────────────────────────────┐
│ Phase 4: Linux Kernel                                      │
├────────────────────────────────────────────────────────────┤

Kernel Entry (zImage decompressed at 0x8000)
    │
    ├─ ARM architecture initialization
    │  └─ MMU setup (virtual memory)
    │  └─ Cache configuration
    │  ├─ Exception handlers setup
    │  └─ Interrupt controller init
    │
    ├─ Device tree parsing
    │  └─ Parse /proc/device-tree/
    │  └─ Identify all hardware
    │  └─ Setup device nodes
    │
    ├─ Core kernel subsystems
    │  ├─ Memory management
    │  ├─ Process management
    │  ├─ Interrupt handling
    │  └─ Timekeeping
    │
    ├─ Device driver initialization
    │  ├─ PS7 UART (console)
    │  ├─ PS7 GPIO
    │  ├─ PS7 QSPI Flash
    │  ├─ FPGA Fabric drivers
    │  │  ├─ AD9361 AXI interface
    │  │  ├─ DMA controllers
    │  │  └─ Clock generators
    │  ├─ AD9361 IIO drivers (libiio)
    │  └─ USB gadget stack
    │
    ├─ Filesystem mounting
    │  └─ rootfs.cpio.gz decompression
    │  └─ Mount as root filesystem (/)
    │  └─ Populate /dev, /proc, /sys
    │
    ├─ Module loading (if applicable)
    │  └─ Load optional kernel modules
    │  └─ Setup device-specific modules
    │
    └─ Init process launch
       └─ Execute /sbin/init (init script)
       └─ Transfer control: Kernel → Init
```

### Kernel Command-Line Parameters

```
bootargs=console=ttyPS0,115200 root=/dev/mtdblock3 rw rootfstype=squashfs

Parameters breakdown:
├─ console=ttyPS0,115200
│  └─ Serial console on UART0 (ttyPS0)
│  └─ Baud rate: 115200
│
├─ root=/dev/mtdblock3
│  └─ Root filesystem location
│  └─ mtdblock3 = QSPI partition 3 (mtd3)
│
├─ rw
│  └─ Mount root as read-write
│
└─ rootfstype=squashfs
   └─ Filesystem type: squashfs
   └─ Compressed read-only filesystem
```

## Phase 5: Init System

```
┌────────────────────────────────────────────────────────────┐
│ Phase 5: Init System / User Space                          │
├────────────────────────────────────────────────────────────┤

Init execution (PID 1)
    │
    ├─ Parse /etc/inittab (if busybox init)
    │  └─ Or systemd unit files (if systemd)
    │
    ├─ Mount filesystems
    │  ├─ /proc (process info)
    │  ├─ /sys (kernel interfaces)
    │  ├─ /dev (device nodes)
    │  └─ /tmp (temporary)
    │
    ├─ Start services
    │  ├─ Syslogd (logging)
    │  ├─ SSH daemon (ssh root@192.168.2.1)
    │  ├─ USB gadget serial console
    │  ├─ Hostname setup
    │  └─ Network configuration
    │
    ├─ Device initialization
    │  ├─ Enumerate USB (libiio for IIO)
    │  ├─ Configure AD9361 transceiver
    │  └─ Bring up Ethernet (if connected)
    │
    ├─ User shell launch
    │  └─ If interactive mode
    │  └─ Login shell on console
    │
    └─ Ready for user interaction
       ├─ SSH access: ssh root@192.168.2.1
       ├─ USB IIO: libiio API access
       ├─ Web interface (if enabled)
       └─ Interactive applications
```

## Boot Flow Timeline

### Timing Breakdown (approximate)

```
Phase         Component              Time    Cumulative
──────────────────────────────────────────────────────
ROM            Boot detection        0.2 s   0.2 s
               QSPI read FSBL        0.5 s   0.7 s

FSBL           Load and verify       0.3 s   1.0 s
               PS7 init              0.2 s   1.2 s
               Load U-Boot           0.8 s   2.0 s

U-Boot         Startup               0.2 s   2.2 s
               Environment           0.1 s   2.3 s
               Load FIT image        1.5 s   3.8 s
               FPGA config           0.3 s   4.1 s
               Kernel setup          0.2 s   4.3 s

Kernel         Decompress+start      0.5 s   4.8 s
               Device init           0.8 s   5.6 s
               Rootfs mount          0.3 s   5.9 s

Init           Services start        0.5 s   6.4 s
               Ready for use         0.1 s   6.5 s

Total time to operational: ~6.5 seconds
```

## Recovery Scenarios

### Scenario 1: Corrupted Bootloader

```
Symptom: Device doesn't boot at all

Recovery via JTAG:
1. Load FSBL and U-Boot into RAM
   $ xsdb run-xsdb.tcl

2. From U-Boot console:
   => sf probe
   => sf erase 0 0x100000
   => loady 0x1000000
   (load new boot.bin via YMODEM)
   => sf write 0x1000000 0 0x100000
   => boot

3. Device should now boot normally
```

### Scenario 2: Corrupted Kernel/Rootfs

```
Symptom: Kernel panic after boot

Recovery:
1. Reboot in DFU mode
   $ dfu-util -l

2. If DFU unavailable, use JTAG bootstrap

3. Reflash via:
   $ dfu-util -d 0456:b674 -D build/pluto.dfu -R

4. Device reboots with working firmware
```

### Scenario 3: FPGA Configuration Failure

```
Symptom: Device boots but RF interface unavailable

Recovery:
1. Check FPGA bitstream:
   $ dmesg | grep -i fpga

2. Verify AD9361 interface:
   $ iio_info | grep ad9361

3. If missing:
   a) Reboot device (FPGA reload)
   b) Check power supply (1.8V to RF section)
   c) Rebuild and reflash FPGA bitstream
      $ make hdl/projects/pluto
      $ make build/pluto.dfu
```

## Environment Variables

### Critical U-Boot Environment Variables

```
bootcmd         Command to run at startup
                Default: run boot_config

bootargs        Kernel command-line arguments
                Default: console=ttyPS0,115200 root=/dev/mtdblock3

ethaddr         Ethernet MAC address
                (Can be changed to custom value)

ipaddr          IP address (if no DHCP)
                Default: 192.168.2.1

netmask         Network mask
                Default: 255.255.255.0

gateway         Default gateway (if needed)
                Default: 192.168.2.254

mtdparts        MTD partition layout
                Defines partitions in QSPI

dfu_altinfo     DFU alternate configurations
                Maps DFU targets to MTD partitions
```

### Examine Environment

```bash
# SSH into device
ssh root@192.168.2.1

# View U-Boot environment (if accessible)
cat /proc/cmdline

# View kernel boot parameters
dmesg | head -20

# Check FPGA status
cat /sys/devices/platform/amba/*/version

# Check IIO device
iio_info
iio_attr -r ad9361-phy frequency
```

## Device Interfaces at Boot

### USB Enumeration

```
Device Tree Node:
ps7_usb_0 {
    compatible = "xlnx,zynq-usb-2.20.a";
    reg = <0xe0002000 0x1000>;
    interrupts = <0 21 IRQ_TYPE_LEVEL_HIGH>;
    phy_type = "ulpi";
    dr_mode = "peripheral";
};

Boot Sequence:
1. U-Boot: USB gadget registration
2. Linux: USB gadget driver load
3. Device appears as USB IIO interface
4. Host can communicate via libiio
```

### Device Tree Blob Selection

```
U-Boot FIT Image supports multiple DTBs:
├─ fdt@1: zynq-pluto-sdr.dtb (RevA)
├─ fdt@2: zynq-pluto-sdr-revb.dtb (RevB)
└─ fdt@3: zynq-pluto-sdr-revc.dtb (RevC)

Selection based on:
• Hardware revision (from EEPROM)
• Or first available DTB
• Kernel uses selected DTB for device discovery
```
